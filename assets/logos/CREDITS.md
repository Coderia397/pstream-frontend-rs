# Logo credits

The Streams wordmark and mark are set in **Baby Blocks** by **Colorful Typhoon** (http://www.geocities.jp/kitschlabo/).

The font is linkware. Its readme (README.gif in the download) says: freeware for personal use only; you may use it for non commercial personal use as long as you provide a link to the designer's website. This project is open source and non commercial, and links to the designer in the site footer and here. If the project becomes commercial, contact the designer for a commercial licence before continuing to use it.

The font file itself is not part of this repository. `scripts/make_logos.mjs` rebuilds every logo and icon from it:

    node scripts/make_logos.mjs "/path/to/baby blocks.ttf"

The brand color of the mark, tiles and favicon is the `PRIMARY` constant at the top of that script.
